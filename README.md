# 📝 To-Do List Application

A simple and professional command-line To-Do List Application built with Python. This project helps users manage daily tasks efficiently using a JSON file for permanent data storage.

---

## 📌 Project Overview

The To-Do List Application allows users to:

- Add new tasks
- View all tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- View pending tasks
- View completed tasks
- Sort tasks
- View task statistics
- Store data permanently using a JSON file

This project follows a modular structure where each file has its own responsibility, making the code clean, organized, and easy to maintain.

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/your-username/ToDo-List-App.git
```

Go to the project folder:

```bash
cd ToDo-List-App
```

Run the application:

```bash
python main.py
```
